# Controls and gameplay

## Desktop prototype
- **W / Up Arrow:** move the boat forward
- - **S / Down Arrow:** move backward / brake
  - - **A / Left Arrow:** steer left
    - - **D / Right Arrow:** steer right
      - - **Esc:** pause or resume (if supported by the current script)
        - - **R:** restart (if supported by the current script)
         
          - ## Objective
          - Navigate the flooded village, reach stranded villagers, and complete the rescue objective before the timer expires. Avoid treating this prototype as an emergency-response simulator; it is a fictional game.
         
          - ## Android testing checklist
          - - Test on-screen touch controls on a physical device.
            - - Confirm HUD text remains readable at phone aspect ratios.
              - - Test pause/resume, restart, timer and rescue counter.
                - - Check performance on low-end devices and reduce procedural object count if needed.
                  - - Verify portrait/landscape behavior before publishing.
